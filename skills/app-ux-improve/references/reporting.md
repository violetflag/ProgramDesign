## 최종 보고 (사용자에게, 한국어)

사용자가 마지막 메시지만 봐도 전체를 알 수 있게 쓴다. 500자 안팎, 머리말 없이 바로 결론.

```
<한 줄 결론: 무엇을 어디에 올렸는지>

**결과물**
- PR (초안): 링크 — 브랜치, 버전, 파일 수
- 검토 보고서 / 캔버스 링크

**고친 것**
- 주제별로 2~5개 항목. 사용자 눈높이 문장.

**검증**
| 측정 | 이전 | 이후 |   ← 숫자는 표로, 문장에 섞지 않는다

**의도적으로 남긴 것 / 되돌린 것**
- 왜 남겼는지 한 줄씩.

<다음 행동 한 줄: "확인 후 '리뷰 가능으로 바꿔 줘' 또는 '머지해 줘'라고 하시면 처리하겠습니다.">
```

- 사용자가 묻지 않은 질문을 던지지 않는다. 선택지를 늘어놓지 않고 권장을 말한다.
- 사용자가 질문을 섞어 보냈으면("이 문구 계속 바뀌는 거야?") 번호대로 사실로 답한다.
- 캔버스는 비공개임을 한 번 알린다.
- PR 이벤트 알림이 자기 작업의 메아리면 "메아리, 새로 할 일 없음" 한 줄로 끝낸다.
